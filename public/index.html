Panduan Catat

Kelola tugas dari satu daftar.

  1. Tambah: klik Tambah tugas, isi judul dan kategori, lalu simpan. Tenggat dan catatan boleh kosong.
  2. Edit: klik Edit pada tugas, sesuaikan data, lalu Simpan perubahan.
  3. Selesai: centang kotak tugas untuk menandai selesai. Hilangkan centang untuk mengembalikannya ke Belum mulai.
  4. Hapus: klik Hapus pada baris tugas, periksa judulnya, lalu konfirmasi.
  5. Temukan: gunakan filter status/kategori, pencarian, atau urutan tenggat/prioritas.

Enam tugas awal dibuat sebagai contoh untuk demo. Data ini bukan agenda pribadi pengguna. Perubahan disimpan pada server lokal dan tetap tersedia setelah server dijalankan ulang.

REST API

Empat method dipanggil langsung oleh frontend.

GET /api/tugas
Menampilkan semua tugas. Status 200.
POST /api/tugas
Menambahkan tugas dari form. Status 201.
PUT /api/tugas/:id
Mengubah tugas atau status selesai. Status 200.
DELETE /api/tugas/:id
Menghapus tugas setelah konfirmasi. Status 200.

POST dan PUT mengirim JSON berisi judul, kategori, tenggat, prioritas, status, dan catatan. PUT mengganti seluruh kolom tugas. Input tidak valid menghasilkan 400 dan ID yang tidak ditemukan menghasilkan 404.
